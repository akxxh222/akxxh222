## Featured Projects

### 1. CC-RAG — Confidence-Calibrated Retrieval-Augmented Generation

**Tech:** Python · Gemini · Flask · PostgreSQL · pgvector · Scikit-learn

Built a financial-document question-answering system that combines semantic retrieval with learned confidence estimation. Uses retrieval evidence and answer-consistency signals to decide whether to **ANSWER**, **HEDGE**, or **REFUSE**, aiming to reduce unsupported responses.

### 2. Casting Defect Detection

**Tech:** Python · TensorFlow · Flask · REST API

Developed a CNN-based image classifier for industrial quality inspection and integrated it into a Flask web interface and REST API. Achieved **98% test accuracy** on approximately **7,500 images**.

### 3. Trekking Management System

**Tech:** Python · Flask · REST API · HTML

Built a web application with a Flask backend and HTML interface to manage trekking-related records through **create, read, update, and delete (CRUD)** operations.
